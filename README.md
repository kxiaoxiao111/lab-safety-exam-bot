## 功能特点

- **题库优先**：本地 `bank.json` 存有题库与标准答案，命中即答，**不联网也能跑**
- **自动交卷**：自动点击「交卷」并处理确认弹窗，读取分数
- **不满分自动重考**：可设置最多重考 N 次，每次自动把标准答案并入题库
- **图形界面**：tkinter 界面，显示实时日志与历史成绩
- **大模型可选**：题库未命中时可调用通义千问兜底（需自备 API Key）
- **登录手动、检测自动**：不模拟登录操作，只检测是否已进入考试系统，避免误点

## 题库格式

`bank.json` 是一个字典，键为题干的规范化前缀，值为题目信息：

```json
{
  "以下液体中投入金属钠最可能发火燃烧的是": {
    "q": "以下液体中，投入金属钠最可能发火燃烧的是：",
    "type": "单选题",
    "key": "C",
    "correct_text": "水",
    "opts": [["A","无水乙醇"],["B","苯"],["C","水"],["D","汽油"]]
  }
}
```

- `key` 是正确选项字母，多选题可能形如 `"ACD"`
- `correct_text` 用于**按选项文本匹配**，避免考试时选项顺序被打乱
- 想把其他题库加进来，按同样格式合并即可

## 运行方式

### 方式一：使用发行包（推荐给非技术用户）

下载 Release 中的压缩包，解压后：

1. 双击 `1 首次使用·准备环境.cmd` —— 自动检查环境
2. 双击 `2 启动程序.cmd` —— 打开界面
3. 点「① 打开登录窗口」登录一次，再点「② 开始考试」

发行包内已包含便携 Python 与 Chrome，**无需安装任何东西**。

### 方式二：从源码运行（开发者）

```bash
pip install selenium
python exam_gui.py
```

可选（启用大模型兜底）：

```bash
pip install dashscope
set DASHSCOPE_API_KEY=sk-xxxx
```

## 自行构建发行包

发行包 = 本仓库源码 + 便携 Python + Chrome for Testing。

1. 下载 **Python 嵌入式/完整版**（需含 tkinter），放到 `python\`
   - 建议直接用完整安装版拷贝，并删除 `Lib\site-packages`、`Lib\test`、`Doc`、`include`
2. `pip install --target python\Lib\site-packages selenium`
3. 下载 **Chrome for Testing**（win64）与对应版本 **chromedriver**，放到 `chrome\`
   - 版本清单：https://googlechromelabs.github.io/chrome-for-testing/
   - 国内可用镜像：`https://registry.npmmirror.com/-/binary/chrome-for-testing/`
4. 把仓库里的 `.py`、`bank.json`、`.cmd` 一起放到根目录
5. 打包成 zip

## 工作原理

```
启动 → 环境自检
  ↓
打开统一身份认证 → 用户手动登录 → 用户手动点进考试系统
  ↓
程序轮询所有标签页，检测是否已登录（看右上角用户名，而不是看元素是否存在）
  ↓
进入考试 → 逐题读取题干与选项 → 查题库 → 点击答案 → 下一题
  ↓
交卷 → 处理确认弹窗 → 读分数
  ↓
100 分 → 结束；不满分 → 从答题结果页抓标准答案并入题库 → 重考
```

### 几个关键实现细节

- **登录判定**：未登录时页面也有 `.person_info_card` 元素，但内容是「登 录」，所以必须看**内容**而非元素存在性；同时校验登录后才出现的 `.app_logout`
- **选项匹配**：先精确匹配选项文本，再做**长度受控**的前缀匹配，避免「水」误匹配到「无水乙醇」
- **翻页同步**：点击「下一题」后等待题干真正变化再读取，避免旧 DOM 导致点错
- **交卷状态机**：先判断是否已到成绩页，再找弹窗按钮，避免页面跳转后在错误的页面上找按钮

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: dashscope` | 未安装大模型依赖 | 可不装，题库模式照常工作 |
| `SessionNotCreatedException` | 浏览器/驱动版本不匹配 | 用发行包，或重新下载匹配版本 |
| 开考后无反应 | 登录态失效 | 重新点「① 打开登录窗口」登录一次 |
| 交卷后读不到分数 | 页面加载慢 | 查看 `日志\` 目录下的记录 |

## 已知限制

- 仅适配当前页面结构，网站改版会失效
- 题库覆盖不完整时，未命中的题目会走大模型或留空
- 登录环节必须手动操作（考试系统登录页无法直接使用，需从学校门户进入）
