- 交卷后自动跳转到考试系统官方成绩页

## 使用方法

1. 解压到桌面或 D 盘（不要放 `C:\Program Files`）
2. 双击 `1 首次使用-准备环境.cmd`（只做一次）
3. 双击 `2 开始考试.cmd`
4. 浏览器里登录统一身份认证 → 进入大厅 → 点「安全教育培训考试」
5. 之后全自动：答题、交卷、显示成绩

## 工作原理

```
浏览器登录（统一身份认证）
   ↓ 自动从浏览器取登录凭证（Cookie）
接口直连答题（startExam → examing → submitAnswer → finishExam）
   ↓
交卷 → 跳转考试系统官方成绩页
```

不修改任何客户端、不注入脚本，只是把「点页面」换成「调接口」。

## 常见问题

**Q：双击提示「Windows 已保护你的电脑」**
A：点「更多信息」→「仍要运行」，只需一次。

**Q：提示「未能获取登录凭证」**
A：说明没进到考试系统。先登录门户 → 进大厅 → 手动点「安全教育培训考试」，再重新运行。

**Q：提示「题库中未匹配」**
A：有题不在题库里。程序会写入 `未匹配题目.txt`，可以据此补库。

**Q：想让用时看起来正常一点**
A：`2 开始考试.cmd` 里加一行 `set EXAM_DURATION=600`，每场会跑满 10 分钟再交卷。

**Q：能不能用大模型兜底题库外的题**
A：可以，设置环境变量 `DEEPSEEK_API_KEY`，未命中的题会调用 DeepSeek 作答。
